# Scenario Card Presentation Verification

The live PFC server was restarted after applying migration `simple_creator.0015_tournamentscenario_image`.

The Scenario Admin page at `/admin/simple_creator/tournamentscenario/3/change/` was checked after restart. Its Basic Information section now contains an **Image** file input with the explanation that the image is optional and will appear on the Simple Tournament Creator card. The input accepts a single uploaded file; leaving it blank retains the text-only layout.

The Simple Tournament Creator at `/simple/` was also checked after restart. Scenario descriptions are now sourced from literal hidden template content and inserted with `textContent`, rather than being taken from an escaped JavaScript data attribute. The description container uses `white-space: pre-line`, so normal newline characters display as readable line breaks and blank lines are retained as paragraph spacing. No raw `\\u000D\\u000A` sequence is shown by the current card renderer.

The optional image wrapper is hidden when a selected Scenario has no image, preserving the current card layout. If an admin uploads one image, the renderer sets it through the image element's `src`, displays it directly below the card title, and applies responsive full-width `object-fit: cover` styling with a 210px maximum height.

The live creator DOM was additionally checked after restart. It contains four literal Scenario description templates, no longer exposes any `data-desc` attribute on Scenario options, and applies computed `white-space: pre-line` styling to the description panel. The optional Scenario image element is present while its wrapper is hidden for the current image-less selected Scenario. This confirms the existing layout remains unchanged when no image has been uploaded.
